# 👨‍💻 Rahul Roy — Portfolio

A modern, responsive portfolio website showcasing my journey as a Software Engineer specializing in backend development, fullstack engineering, and AI.

## ✨ Features

- **Modern Design** — Clean, gradient-rich UI with smooth animations
- **Fully Responsive** — Optimized for desktop, tablet, and mobile
- **Performance** — Single-file HTML with embedded CSS/JS, no dependencies
- **Sections**:
  - Hero with social links
  - About with stats
  - Technical skills
  - Work experience timeline
  - Projects showcase
  - Achievements
  - Contact

## 🚀 Quick Start

1. Clone the repository:
```bash
git clone https://github.com/RahulRoy22/RahulRoyPortfolio.git
cd RahulRoyPortfolio
```

2. Open `index.html` in your browser:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — Intersection Observer for scroll animations
- **Google Fonts** — Inter & JetBrains Mono

## 📂 Structure

```
RahulRoyPortfolio/
├── index.html          # Main portfolio page (self-contained)
└── README.md           # Project documentation
```

## 🎨 Customization

All styles are embedded in `<style>` tags. Key CSS variables:

```css
--bg: #0a0a0f;          /* Background */
--accent: #7c6af7;      /* Primary accent */
--accent2: #5eead4;     /* Secondary accent */
--accent3: #f472b6;     /* Tertiary accent */
--text: #e2e8f0;        /* Text color */
--muted: #64748b;       /* Muted text */
```

## 📱 Responsive Breakpoints

- Desktop: > 768px
- Mobile: ≤ 768px
